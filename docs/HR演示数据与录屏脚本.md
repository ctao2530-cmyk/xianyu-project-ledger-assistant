## 建议录屏顺序（约 3 分钟，可剪掉模型等待时间）

1. **工作台（约 20 秒）**：展示本月收入、当前待回款和待处理事项。开场说明：“这是我开发的循营一人经营工作台，下面使用隔离的虚构数据演示核心业务流程。”
2. **客户 → 需求 → 项目（约 40 秒）**：选择云栖工作室，展示会话、正式需求四层阅读与关联项目；进入项目详情，展示开发任务和合同回款。
3. **收支经营（约 30 秒）**：切换“本月”和“全部时间”，展示收入支出明细；切换“回款跟进”，解释确认到账与待回款的区别。
4. **小策（约 60 秒，不含生成等待）**：选择“Codex 深度分析”和“经营全局”，发送下面的问题。展示答案及“用时…”中的实际只读查询证据。本机录屏验证已保存“HR 演示：收入与项目概览”对话；仓库不附带该数据库或回答，克隆后需在自己的演示环境中实际提问。
5. **经营分析 / 服务商品（约 30 秒）**：展示月度收支对比、项目负载提示与商品趋势。结束时说明：“小策依据同一份业务账本给出判断；任务完成、客户验收与回款状态分别记录。”

可直接复制的提问：

```text
请总结我本月的收入、支出、收支净额和当前待回款情况，并明确区分本月与累计口径。
```

```text
我现在有哪些项目？哪些正在开发、等待验收、已经完成、尚未启动？接下来优先做什么？请用项目名称和具体事实说明，任务完成不等于客户验收。
```

```text
请用三句话总结本月收入、支出和项目进度，并给出今天优先做的一件事。
```

小策需要使用者本机安装并登录 Codex，并在 `.env` 设置可用的 `CODEX_COMMAND`。回答实际调用模型生成，依赖网络与账号可用性，措辞和耗时可能变化。演示数据库没有索引个人知识库，不会伪造知识引用。

## 操作边界

- 已开放核心页面浏览、演示账本保存、演示收款确认与小策对话。记录新收支后，小策再次提问会读取更新后的演示账本，原有数字也会相应变化。
- 真实客户发送、平台采集、凭证修改、GPT 客户授权、自动订阅和 Codex 开发执行在演示入口均未开放；演示不会替你操作真实平台。
- 演示数据位于 `data/demo-recording/`，种子代码为 `backend/app/demo_seed.py`；初始化有目录标记和数据库路径校验，已有数据不会被静默重置。需要恢复初始数据时，应先备份这份演示库再单独重建，不能向真实库执行种子脚本。
- 录屏使用 `demo.localhost:8877`；切回 `127.0.0.1:8877` 就是实际经营工作台。
