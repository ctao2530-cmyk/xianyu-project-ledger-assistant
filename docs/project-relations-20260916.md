# 接单与交付迭代：项目业务关联视图

## 本轮取舍

用户选择优先改善客户接单与项目交付。保留客户沟通、正式需求及版本、开发任务、客户验收、合同与回款；商品经营保持原有功能，本轮不扩展。尚无使用频率证据，不以“复杂”推断功能无用，也不删除记录或兼容路由。

- 精简：项目详情的“管理关系”和“编辑基本信息”重复按钮统一到头部“编辑项目”；原有关系预览、确认和编辑能力保留。
- 新增：接单项目头部下方的折叠“业务关联图”，以当前项目为中心展示客户档案、来源会话、正式需求与验收、开发任务、合同回款。默认收起，不增加首页看板或主导航。
- 复用：正式需求已有四层关系图，不再复制一套需求图谱。
- 修复：窄上下文栏的四列指标改为单列；正式需求读取中、读取失败、未关联分别呈现，失败可重试。

## 数据边界

纯前端只读投影，复用账本快照及现有项目正式需求接口，不增加 API、后台采集、模型调用或数据库迁移。客户按 customerId，会话仅按项目已记录的 conversationId；不从昵称或客户其他会话推断项目来源。正式需求同时核对项目、客户和 case_id。回款复用既有财务计算（含现有退款和结算规则）。开发完成不表示验收，图中不推断客户验收状态；节点进入正式版本验收记录区。

桌面为静态关系连线，手机为语义列表，不依赖拖拽、动画或额外图形库。缺失关联用虚线卡片明确标记，未关联会话没有伪链接。图谱不提供关系编辑。
